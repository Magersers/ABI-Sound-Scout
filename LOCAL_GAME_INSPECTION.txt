Проверка локальной установки Arena Breakout: Infinite
11 ноября 2026, Europe/Moscow. Версия установленной игры: 1.0.0.151.22.
Steam app 2073620; build 26473477.
Установка: C:\Program Files (x86)\Steam\steamapps\common\ABInfinite

Результат для помощника полевого торговца
Все 189 предметов каталога сверены с локальной UACommonItemTable.
Для 82 групп, используемых публичным каталогом торговца, все 1146 строк
с положительными весами совпали с локальной MysteryBoxItemConfig.
Объединение этих строк содержит ровно 189 предметов, без пропусков.
Две другие группы с порохом не добавлены: их активность у торговца
не подтверждена доступной таблицей выбора торговых пулов.

Для каждого предмета установлены события поднятия и отпускания,
Wwise Event ID и Media ID. У 187 предметов исходные имена событий
подтвердились, у двух исправлены: «Ожерелье с камнями» и кулон
«Звезда Камоны» используют Item_Necklace_Up/Down. Эти события связаны
с тем же аудио, что GoldChain, и не дают различимого по звуку класса.
Итог: 39 пар событий, 78 событий, 76 уникальных локальных аудиофайлов.
Все они добавлены в программу как lossless FLAC. Прежние публичные
записи сохранены; всего загружаются 156 привязок эталонов.

Что прочитано в игровых файлах
176 игровых PAK, около 88,8 GiB на диске. У 59 базовых архивов индекс
зашифрован, у 117 патчей открыт. Открытые индексы дали 2780 записей,
1491 уникальный путь. Из открытых частей патчей извлечены общая
таблица предметов и русская/английская локализации.
В общей таблице прочитаны 16758 строк с проверкой границ и ключей ID;
она также включает служебные записи. Из них 2118 сопоставлены с
публичным инвентарным индексом для независимой проверки структуры.
В программу включён только выбранный пользователем скрытый груз.

Из базового pakchunk2-WindowsNoEditor.pak прочитаны физические
заголовки 41555 записей. Конец обхода точно совпал с началом индекса
на смещении 2874268966. Зашифрованные тела пропускались. Доступные
сжатые блоки декодировались выборочно, без распаковки всей установки.
Нужный банк Wwise: 1777182227, запись архива на смещении 1929451520.
Связи подтверждены цепочкой Event -> Action -> Sound/Container ->
sourceID -> DIDX -> DATA. Файлы извлечены по точным смещениям банка.
Исходный формат Wwise ADPCM 0x8311, 44100 Гц, стерео. Конвертация
в FLAC проверена побитовым сравнением декодированного PCM.

Русские названия
188 названий торговца найдены в локальной русской локализации по
namespace UACommonItemTable и ключу <ID>_Name; английская строка и
хеш исходного текста сверены. Для DVD сохранено понятное «DVD-диск».
Несколько игровых сокращений развёрнуты для удобства.

Проверяемые файлы в папке data
ITEM_SOUND_MAP.json — все 189 предметов и точные звуковые привязки.
LOCAL_AUDIO_MANIFEST.json — параметры и хеши локальных звуков.
LOCAL_MAPPING_EVIDENCE.json — исправленные события и смещения строк.
item_names_ru.json — русские имена с происхождением.
local_audio_references.json и local_catalog_overrides.json — данные
для сохранения исправлений при обновлении публичной базы.

Границы проверки
Проверены структура ресурсов, связи и распознавание эталонов с шумом.
Громкость, изменение тона, эффекты Wwise и смешивание звуков во время
игры могут влиять на узнаваемость. Совпадение звука не доказывает
единственный предмет: у разных вещей часто одинаковые записи.
Игровые файлы не изменялись, процесс и память игры не читались,
игра не перезапускалась. Захват экрана не включался.
