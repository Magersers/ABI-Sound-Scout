# ABI Sound Scout

Помощник для скрытого груза полевого торговца в **Arena Breakout: Infinite**.
Слушает звук перемещения предмета и показывает возможные предметы на русском.
Фильтр по форме предмета сужает список совпадений.

**[Скачать готовую программу для Windows x64](https://github.com/Magersers/ABI-Sound-Scout/releases/latest)**

## Быстрый запуск

1. Скачайте `ABI-Sound-Scout-0.4.0-win-x64.zip` из раздела Releases.
2. Распакуйте **весь архив**, затем запустите `ABI Sound Scout.exe`.
   Python устанавливать не нужно; папки `data` и `_internal` оставьте рядом с EXE.
3. В игре включите оконный режим без рамки. В помощнике выберите устройство,
   через которое слышна игра.
4. Выберите **«Клавиша открытия»** в главном окне — по умолчанию **F5**.
   Нажмите её в игре и перетащите скрытый предмет, когда появится «СЛУШАЮ».
5. Укажите форму клавишей **1–9**. Повторное нажатие клавиши открытия
   скрывает окно и останавливает прослушивание.

Если клавиши не работают при фокусе в игре, закройте помощник и запустите
его **от имени администратора**. Перед обновлением закройте старую версию.

## Управление

| Клавиша | Действие |
| --- | --- |
| Выбранная клавиша, по умолчанию F5 | Показать/скрыть помощник и включить/выключить прослушивание |
| F6 | Разрешить работу мышью с окном и его перемещение |
| F7 | Следующая страница кандидатов |
| 0 | Все размеры |
| 1 / 2 / 3 / 4 | 1×1 / 1×2 / 1×3 / 1×4 |
| 5 / 6 / 7 | 2×2 / 2×3 / 2×4 |
| 8 / 9 | 3×3 / 3×4 |

Клавиша открытия меняется сразу и сохраняется между запусками. Доступны
F1–F12, кроме F6/F7, A–Z, Insert, Home, End, PageUp и PageDown. Буквы
соответствуют физическим клавишам английской раскладки. Сочетания с
Ctrl/Alt/Shift/Win игнорируются. Цифры и F6/F7 действуют во время прослушивания.
Поворот предмета учитывается: 2×3 и 3×2 — одна форма.

## База и распознавание

- 189 предметов скрытого груза с русскими названиями.
- 39 пар звуковых событий, 76 локальных FLAC-файлов и публичные варианты
  эталонов: всего 156 привязок для сравнения.
- Привязки предмет → событие Wwise → аудиофайл сверены с ресурсами игры
  версии **1.0.0.151.22** 11 ноября 2026 года.
- Один звук может соответствовать нескольким предметам. Сходство звука
  не является вероятностью выпадения; некоторые группы звучат одинаково.
- Цены справочные, из снимка базы **1.0.0.151.10 от 22.09.2026**.
  Они не отражают текущие цены рынка игроков.

Используется системный звук выбранного устройства через WASAPI loopback.
Микрофон не используется. Распознавание работает локально; аудио не
отправляется в интернет и не сохраняется автоматически. Музыка,
голосовой чат, эквалайзер и наложенные эффекты могут мешать сравнению.

## Запуск из исходников

Windows x64, Python 3.12 с Tkinter:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Обновление публичного каталога: `python tools/download_catalog.py`.
Русские названия и проверенные локальные звуковые варианты сохраняются.
После обновления перезапустите приложение.

## Проверка и сборка

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\build.ps1 -Python .venv\Scripts\python.exe
```

Готовая папка: `dist/ABI Sound Scout`. Проверка собранного EXE без окна,
прослушивания и регистрации клавиш:

```powershell
Start-Process -FilePath '.\dist\ABI Sound Scout\ABI Sound Scout.exe' -ArgumentList '--self-test', 'self-test.json' -Wait
Get-Content self-test.json
```
