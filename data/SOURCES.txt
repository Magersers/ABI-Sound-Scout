Источник текущего локального снимка: опубликованные на странице ABI Builder
данные версии 1.0.0.151.10, обновлённые источником 22 сентября 2026 года.
Дата скачивания записана отдельно в catalog.json: fetched_at.
Дата скачивания НЕ означает, что цены или состав каталога обновлены сегодня.
На странице ABI Tracker 11 ноября 2026 отображалась более новая версия
1.0.0.151.17, поэтому этот каталог нельзя выдавать за последнюю версию игры.

Итог версии 0.4.0: 189 предметов скрытого груза, 39 пар звуковых событий.
В sounds находятся 78 публичных OGG-записей; в sounds_local — 76
оригинальных файлов, извлечённых из игры и преобразованных в lossless FLAC.
Из-за общих звуков для разных событий получается 156 привязок эталонов.
URL публичных записей и SHA-256 файлов записаны в catalog.json.

Локальная проверка: установленная Steam-версия 1.0.0.151.22, 11.11.2026.
Таблица UACommonItemTable из патча 22 дала ID предметов, размеры и
события. Привязка к аудио подтверждена явными ссылками Wwise HIRC:
Event -> Action -> Sound/Container -> sourceID -> DIDX -> DATA.
Исходный банк: 1777182227, запись по смещению 1929451520 в базовом
pakchunk2-WindowsNoEditor.pak. Отдельные зашифрованные данные не читались.
Имена событий ожерелья и кулона «Звезда Камоны» исправлены на Necklace;
их публичные эталоны совпадают с GoldChain, поэтому имена событий
не доказывают возможность различить эти предметы по одному звуку.
ITEM_SOUND_MAP.json: все 189 предметов и их точные звуковые привязки.
LOCAL_AUDIO_MANIFEST.json: источники, форматы и хеши локальных записей.
LOCAL_MAPPING_EVIDENCE.json: два исправления и проверяемые смещения.
Состав 189 предметов подтверждён положительными весами 82 групп
MysteryBoxItemConfig, используемых публичным каталогом торговца.

contact_price — опубликованная цена продажи контакту в Koen.
reference_price — опубликованная справочная базовая стоимость.
Ни одно из полей не является текущей ценой рынка игроков.
Состояние предмета и изменения игры могут менять фактическую стоимость.
Один звук может соответствовать нескольким предметам; размер помогает
сузить список, но совпадение звука не доказывает конкретный предмет.

Русские названия записаны в поле name_ru для всех 189 предметов.
Исходные английские названия сохранены в name. Словарь item_names_ru.json
содержит соответствие ID, исходного имени и перевода, а также его источник.
Текущий источник 188 русских названий — локальная Game/ru/Game.locres
патча 22, namespace UACommonItemTable и ключи <ID>_Name. Английская
локализация и хеш исходной строки сверены для каждого совпадения.
Несколько сокращений развёрнуты для удобства; оригинальная строка
игры сохранена в поле game_name_ru. Для DVD оставлено «DVD-диск».
Первоначальный словарь сверялся со сторонним ABI Database:
https://arenabreakout-infinite.com/ru/items/
https://arenabreakout-infinite.com/items/
Обновлятор сохраняет перевод только при совпадении ID и английского имени.
local_catalog_overrides.json сохраняет две локальные поправки событий;
local_audio_references.json сохраняет проверенные FLAC-варианты.
При версии публичной базы новее проверенной игры локальные звуковые
поправки автоматически не переносятся. Цены остаются справочными.
